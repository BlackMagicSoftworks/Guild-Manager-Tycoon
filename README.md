# Guild Manager Tycoon

> 🚧 Work in Progress — Early Prototype

Guild Manager Tycoon is an independently developed management game built
with Unity and C#. The player manages an adventurer guild by accepting
contracts, assembling parties, managing adventurers, and developing the
guild over time.

The project is currently in early prototype development and is being used
to build my experience designing and implementing larger interconnected
gameplay systems independently.

## Currently Implemented / In Development

- Contract/job board interface
- Contract details and acceptance workflow
- Accepted contract management
- Adventurer cards
- Party assignment
- Guild Hall UI navigation
- Early expedition workflow

## Planned Systems

- Contract success calculations and outcomes
- Adventurer classes and progression
- Health and energy management
- Training
- Crafting
- Guild resources and supplies
- Additional guild facilities and progression systems

## Development

**Engine:** Unity  
**Language:** C#  
**Version Control:** Git / GitHub  
**Development Status:** Early Prototype

Unlike the coursework projects on this profile, Guild Manager Tycoon is
an independent project that I am designing and developing from the ground up.

The project is actively in development, so systems and architecture may
change substantially as the prototype evolves.
